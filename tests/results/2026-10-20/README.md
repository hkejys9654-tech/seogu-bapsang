# 서구밥상 예약 동시성·장애 점검 — 2026-10-20

운영 예약에는 쓰지 않고, 앱의 실제 예약·취소 함수를 독립된 가상 사용자와 로컬 Firestore 에뮬레이터에서 실행했습니다. 기존 회귀시험과 장애 주입 시험은 총 **123건 통과 / 실패 0건**입니다.

예상 밖 오류·60초 시간초과·정원 초과·대기번호 중복·예약 인원/좌석 장부 불일치는 위 시험에서 모두 0건입니다. 정원 마감은 정상적인 거절이며 서버 오류로 세지 않았습니다. 단체 시험의 남은 2석은 요청 인원과 순서에 따른 결과로, 단체를 쪼개 예약하지 않습니다.

수정 전 50·100·400명과 단체·중복·취소·장애 9개 시나리오, 수정 후 주요 7개 시나리오를 실행했습니다. 수정 후에는 전원 오류여도 빈 장부만 일치해 합격하는 일이 없도록 완료 여부·예상 성공/마감 건수까지 판정합니다. 이 판정이 전원 오류 결과를 실제로 실패 처리하는 것도 별도로 확인했습니다.

## 발견한 문제와 반영 내용

1. 예약은 저장됐는데 응답만 유실되면 실패로 안내했습니다. 이제 서버에서 본인 예약을 한 번 확인해 존재하면 입장표를 엽니다. 최대 5초만 기다리고, 캐시·미확정 데이터는 성공으로 판정하지 않습니다.
2. 접속 불가·혼잡·권한·이용 한도 오류의 안내가 같았습니다. 오류별로 재확인·재시도·관리자 문의를 구분했습니다.
3. 마감 오류 후 좌석 현황이 오래된 상태로 남을 수 있었습니다. 마감·공유 좌석 마감·운영 종료 거절 시 현황 새로고침을 요청합니다.

응답 유실 복구, 캐시 거절, 확인 시간초과, 계정·날짜 변경, 중복 취소·입장·호출, 예약시간 마감 경계는 오류 주입 회귀시험으로 확인했습니다. 운영 화면도 별도로 열어 초기 표시와 서버 조회의 `연결됨` 상태를 확인했습니다. 실제 직원으로 예약하거나 운영 관리자 기능을 실행하지 않았습니다.
