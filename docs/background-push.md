# 화면을 닫은 뒤 호출 알림 — 배포 준비

2026-10-16 코드 준비 및 자동 테스트 103개 통과. Firebase 프로젝트 로그인과 배포는 아직 수행하지 않았다. 이 문서는 실제 휴대폰 수신 완료를 의미하지 않는다.

## 직원 화면
- 예약 후 입장표에서 호출 알림을 켠다. 성공한 기기만 `앱을 닫아도 알림 받기 켜짐`을 표시한다.
- 아이폰/아이패드는 홈 화면에 추가하고 그 아이콘으로 연 뒤 직접 알림 버튼을 누르도록 안내한다.
- 앱을 열어 다른 날짜를 보고 있어도 FCM 호출을 받을 수 있다. 같은 호출의 실시간 데이터 변경과 푸시가 겹치면 한 번만 표시한다.
- 알림을 끄거나 로그아웃하면 해당 기기의 등록을 해제한다. 다른 직원으로 변경할 때 이전 직원의 기기 등록부터 해제한다.
- 만료된 호출을 표시하지 않으며 알림을 누르면 현재 입장표로 이동한다.

## 배포 순서
1. 기존 `seogu-bapsang` Firebase 프로젝트 권한·요금제·배포된 함수 상태 확인.
2. 프로젝트의 Web Push 인증서 공개 VAPID 키 확인/생성. 서비스 계정·비공개 키는 코드에 넣지 않는다.
3. `functions/README.md`대로 공개 키 설정 후 Node.js 22 함수 배포.
4. `getPushConfig`, 기기 등록·해제 응답 확인.
5. 준비한 웹앱 변경을 main에 반영하고 GitHub Pages 배포 확인.
6. 직원의 실제 기기에서 알림 허용 후 화면 잠금·페이지 닫기·새 호출·클릭 이동을 확인. 실제 직원들에게 불필요한 호출을 보내지 않도록 시험용 예약을 사용한다.

GitHub Pages 배포만으로 Firebase 서버가 배포되지 않는다. 현재 Firebase 플러그인 설치가 실패해 계정 연결이 남았다. 사용자에게 브라우저 직접 로그인 방식 전환 승인을 받은 뒤 이어서 진행한다.
